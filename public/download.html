A free, smooth interactive whiteboard for classrooms. Install it once — it works without internet on iPad, Android, laptops and smart boards.

Install on your device

  1. Open this page in Safari.Is page ko Safari mein kholiye.
  2. Tap Open Teachly, then the Share button ⬆︎.Open Teachly dabaiye, phir upar Share button.
  3. Choose Add to Home Screen ＋ and tap Add."Add to Home Screen" chuniye aur Add dabaiye.
  4. Open Teachly from the home screen. It runs full screen and works offline.Home screen se Teachly kholiye — bina internet ke bhi chalega.
  1. Open this page in Chrome.Is page ko Chrome mein kholiye.
  2. Tap Install app above. If you don't see it, open the menu ⋮ and choose Install app / Add to Home screen.Upar "Install app" dabaiye, ya menu ⋮ se Install chuniye.
  3. Open Teachly from your home screen or app drawer.Home screen se Teachly kholiye.
  1. Open this page in Chrome or Edge (Windows, Mac, Chromebook or an Android smart board).Chrome ya Edge mein kholiye.
  2. Click Install app above, or the install icon ⊕ at the right end of the address bar.Upar "Install app" ya address bar ke install icon par click kijiye.
  3. Teachly opens in its own window and gets a desktop / Start menu icon.Teachly apni window mein khulega, desktop par icon bhi aa jayega.

Works on Android smart panels and Windows (OPS) boards. Pick one way:

A. Board has internet

  1. Open this page in the board's Chrome or Edge browser.Board ke Chrome ya Edge mein yeh page kholiye.
  2. Tap Install app (top of this page or the browser menu ⋮). Teachly gets its own icon on the board."Install app" dabaiye — board par Teachly ka icon aa jayega.

B. No internet, or the browser can't install apps

  1. Download the single file Teachly.html (4 MB) — on the board itself, or on a laptop and copy it to a pen drive.Teachly.html download kijiye, ya laptop se pen drive mein copy kijiye.
  2. On the board, open the file from Files / File Manager — it opens in the browser. No internet or install needed.Board par file kholiye — bina internet ke chalega.
  3. Keep using the same file each time: your lessons are saved inside that board's browser.Har baar wahi file kholiye, lesson save rehte hain.
